description: "Show what extra sales would earn at the next tier"
---

Read CLAUDE.md. Run `npm run rebates -- what-if --json` with the flags the operator gave (--agreement=... --extra=amount (extra sales value, or units for a per-unit agreement, this period)).

Present the result as a short table with the numbers that matter. An empty list means no matching records, not that everything is fine.

Use it to show a customer, or a rep, what reaching the next tier is worth. Never present it as a promise.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a rate, an amount or a claim.
